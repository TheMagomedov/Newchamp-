# Руководство пользователя ТОиР-Проф

Система хранит оборудование предприятия, график ТО, заявки, бригады и материалы. Веб-клиент и приложение Windows работают с одной БД через общий API. Действие, сохранённое в одном клиенте, появляется в другом после обновления данных.

## Новый веб на Python

Запуск из `Champ`: **`./run.ps1`**, затем откройте `http://127.0.0.1:8501`. Это Streamlit; адрес `8000` по-прежнему показывает сохранённый Vue. Учебные аккаунты и права у обоих веб-клиентов одинаковы.

Разделы выбираются слева. В реестре выберите строку и нажмите «Открыть карточку». «Добавить запись»/«Редактировать» показывают формы из метаданных; изменения отправляются только кнопкой сохранения. Удаление и импорт требуют отдельного подтверждения. В заявке есть переходы статусов, материалы и атомарное завершение с отчётом. В календаре выберите любую дату нужного месяца; учебные ТО есть в марте 2027 года, нажмите событие для карточки.

В «Отчёты» выберите вид, период, цеха и формат; «Предпросмотр» читает данные, «Подготовить файл» скачивает временную серверную ссылку в память сеанса, затем кнопка «Скачать готовый файл» отдаёт её браузеру. На диаграммах есть CSV и встроенная кнопка PNG. В аналитике доступны PDF всей сводки и отдельных блоков.

Обзор обновляется раз в 60 секунд. Streamlit не использует SSE; новое открытие/перезагрузка вкладки может сбросить вход и локальные шаблоны. Для смены аккаунта нажмите «Выйти» — данные предыдущего сеанса очищаются. Ни пароль, ни токены входа не записываются в файл. Даты операций — UTC. Инструкции ниже про sessionStorage/SSE/печать страницы относятся к резервному Vue, не Streamlit.

## Вход и роли

Откройте `http://127.0.0.1:8501` (Streamlit), `8000` (резервный Vue) или обновлённый `desktop\bin\Updated\Toir.Desktop.exe`. В приложении Windows адрес API вводится без `/api`. Общий пароль демонстрационных аккаунтов: `ChampDemo2027!`.

| Учебный email | Возможности |
|---|---|
| `admin@toir.local` | Все разделы, пользователи и права |
| `engineer@toir.local` | Оборудование, график, заявки и справочники; импорт оборудования |
| `master@toir.local` | Оборудование и заявки своего цеха, назначение и выполнение работ |
| `member@toir.local` | Заявки своей бригады, разрешённые переходы и расход материалов |
| `manager@toir.local` | Просмотр доступных показателей, данных и отчётов |

Это тренировочные аккаунты, не реальные персональные данные. Инженер может вести справочник материалов, но списание в заявку разрешено администратору, мастеру и члену бригады. Наличие записи или кнопки не отменяет серверной проверки прав. Для смены аккаунта используйте «Выйти», затем войдите заново.

## Ежедневная работа

Начните с «Обзора предприятия» в web или «Обзора» в Windows. Web показывает оборудование, активные и выполненные заявки, простой, среднюю длительность работ и соблюдение графика ТО; ниже доступны диаграммы и списки. Если данных для показателя или исторического тренда нет, выводится пояснение/прочерк, а не выдуманный результат.

Веб получает SSE-события об изменениях доступных пользователю данных. Индикатор соединения показывает состояние; после обрыва клиент пробует восстановить поток и использует резервный минутный опрос. WPF-обзор обновляется раз в минуту, если нет открытого диалога и блокировки. Кнопка «Обновить» запрашивает данные сразу. Просрочки и уведомления вычисляются по сохранённым данным, но это не почтовая/SMS-рассылка. Прочтение уведомлений сохраняется локально для пользователя.

В списках используйте поиск, фильтры, сортировку и страницы. В WPF доступны подробные карточки и редактирование разрешённых записей. Если записей нет, проверьте фильтры и роль: мастер видит свой цех, участник бригады — свои работы. Таблицы можно прокручивать по горизонтали. Глобальный поиск помогает найти оборудование, заявку или бригаду; карточка оборудования связывает историю, заявки и график ТО.

В графике переключайтесь между таблицей и календарём, выбирайте месяц и открывайте запись по дате. Учебные записи есть в марте 2027 года: пустой текущий месяц не означает ошибку. «Создать заявку» из ТО предлагает активного мастера нужного цеха, плановое начало и длительность. Для прошедшего ТО укажите новое начало не раньше текущего времени. Повторное создание по той же записи графика возвращает уже существующую заявку.

Для оборудования нажмите «Добавить», заполните поля со звёздочкой, выберите цех и сохраните. Инвентарный номер должен быть уникальным; даты ввода и списания должны следовать логическому порядку. История показывает смены статуса. Удаление оборудования с активными работами блокируется; допустимое удаление скрывает его с сохранением истории. Учётная запись пользователя при удалении деактивируется. Удаление некоторых справочных записей может быть запрещено существующими связями.

## Заявка от создания до закрытия

1. Войдите мастером и откройте «Заявки на работы» / «Заявки». Создайте текущую или аварийную заявку, выберите оборудование, ответственного мастера, описание и будущий плановый период. Для аварийной заявки укажите причину отказа. Мастер создаёт заявку от своего имени.
2. Для плановой заявки выберите соответствующую запись графика и вид ТО. Оборудование и вид обслуживания должны совпадать с графиком. Новая заявка начинается со статуса «создана».
3. Откройте карточку заявки в web или «Заказ: действия» в WPF. Назначьте свободную бригаду и перейдите в «назначена». Пересекающиеся периоды одной бригады отклоняются.
4. Перейдите в «в работе». Укажите фактическое начало либо используйте серверное текущее время. Если нужны материалы, допустим переход в «ожидает материалов», затем обратно в «в работе».
5. Запишите отчёт и фактическое окончание, завершите заявку статусом «выполнена». Уполномоченный пользователь затем переводит её в «закрыта». Окончание должно быть позже начала; перескочить промежуточные этапы нельзя.

В WPF диалог завершения позволяет добавить материалы одновременно с отчётом и фактическим окончанием. Сервер сохраняет весь набор одной транзакцией: при недостатке материала ни статус, ни частичный расход не применяются. Веб также позволяет работать с материалами отдельно в карточке заявки. При смене статуса клиенты не отправляют неизменённые скрытые поля старой карточки.

Отмена разрешена до начала фактических работ. Статус существующей заявки меняется специальным действием, а не обычной формой редактирования. Для учебных демонстраций используйте новые заявки и не меняйте завершённую исходную историю без необходимости.

Временные значения API и БД — UTC. В WPF поле даты/времени принимает, например, `2027-02-10T09:00:00`; не прибавляйте местный часовой пояс второй раз. Плановое начало новой заявки не должно быть в прошлом относительно её создания.

## Материалы, импорт и отчёты

В карточке заявки откройте материалы, выберите позицию и положительное количество. Списание уменьшит складской остаток; увеличение расхода спишет разницу, уменьшение или удаление вернёт её на склад. Отрицательный остаток запрещён. Цена фиксируется в строке расхода при добавлении: последующая смена справочной цены не переписывает историю. В закрытой/отменённой заявке расход менять нельзя.

Импорт оборудования находится в web и доступен администратору/инженеру. Поддерживаются CSV UTF-8 и XLSX размером до 2 МБ; первая строка содержит точные имена полей API, например `InventoryNumber`, `Name`, `Model`, `WorkshopId`, `CommissionedOn`, `StartedOn`. Ссылки указываются идентификаторами существующих справочников. При ошибке файл не импортируется частично. Отдельного мастера импорта в WPF нет.

В отчётах доступны реестры и аналитические разделы. Сначала выберите вид отчёта, период и фильтры, затем откройте предпросмотр и выгрузите PDF/XLSX/CSV. Период экспорта заявок фильтрует дату создания; реестры оборудования и материалов отражают текущее состояние. Временная ссылка живёт 15 секунд, оба клиента скачивают её сразу. В WPF файл сохраняется в `%LOCALAPPDATA%\Toir.Desktop\Exports`; в web — в папке загрузок браузера. Истёкшую ссылку нужно сформировать заново.

На странице аналитики web раскройте фильтры: можно выбрать несколько цехов, период, тип, оборудование и приоритет, сохранить набор как локальный шаблон или сбросить. Графики поддерживают подсказки и переход к связанным данным; кнопки у блока выгружают PNG/CSV/PDF. В верхней части есть PDF всей аналитики и печать страницы через браузер. В динамике показаны последние 30 дней выбранного периода; итоговые показатели могут относиться ко всему периоду — подпись графика важна.

В WPF настройки темы/шрифта и расположение столбцов сохраняются локально. Горячие клавиши: `F5` — обновить, `Ctrl+F` — поиск, `Ctrl+N` — добавить, `Ctrl+L` — заблокировать. Опция «Запомнить меня» сохраняет зашифрованный DPAPI refresh-токен для текущего пользователя Windows и сервера; пароль в файл не записывается. Для восстановления входа нужен доступный API.

## Блокировка, отсутствие связи и ошибки

WPF блокируется через 15 секунд бездействия, включая открытые формы. Повторно введите пароль того же пользователя: введённые значения сохранятся. Если связь пропала, уже открытый сеанс можно разблокировать прежним паролем; новый вход без сервера невозможен. Эта блокировка относится к WPF, не заявляется для web.

Вне сети WPF показывает только ранее загруженные страницы с датой сохранения. При ошибке записи можно явно добавить действие в очередь. Откройте «Очередь», проверьте запрос и нажмите «Повторить выбранное» после восстановления связи. По умолчанию повтор ручной; автоотправка включается отдельно и проверяет очередь раз в 10 секунд только для того же пользователя и API. Конфликт оставляет операцию в очереди и останавливает автоматические повторы для ручного разбора. Прежний ключ запроса защищает от повторного создания. Удаление из очереди не отменяет действие, которое сервер уже мог выполнить. Операции с паролем в очередь не сохраняются.

Ошибка 409 означает конфликт или бизнес-ограничение; прочитайте сообщение, проверьте даты, связи и остатки. При конфликте версии сохраните свои намерения, закройте форму и перечитайте запись. Ошибка 403 — недостаточные права, 401 — повторный вход, 429 — пауза перед повтором. Не нажимайте «Сохранить» многократно при сетевой неопределённости. Сообщая о сбое, укажите раздел, действие и время, но не отправляйте пароль или токен.
